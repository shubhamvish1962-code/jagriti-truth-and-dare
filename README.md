# Truth & Dare Confession Game (Jagriti Edition) ✨

A cute, interactive, liquid-glass Truth & Dare confession web application crafted with love for **Jagriti**.

## 🌟 Highlights
- **Hirael-Velorah Liquid Glass Aesthetic**: Frosted glass cards, deep space twilight mesh glow, and micro-animations.
- **Truth or Dare Dynamic Questions**: Round 1 to 5 with open blank fields for Jagriti's candid answers.
- **2 Interactive Mini-Games**:
  - Mini Game 1: The Truth & Dare Wheel 🎡
  - Mini Game 2: Heart Catcher Arcade 🎮
- **Background Music**: *"Finding Her"* by Kushagra, Bharath 🎵 with floating controls.
- **Stationary Choice Buttons & Instant Transmission**:
  - Automatic email transmission to Shubham upon submission.
  - Direct WhatsApp send button.
  - Celebration confetti and Official Certificate of Romance.

## 🚀 Built With
- React 19 + Vite
- Web Audio API (sound synthesis)
- Canvas Confetti
- Lucide React
